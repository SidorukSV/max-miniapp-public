# Repository instructions

## Git workflow

- Для этого репозитория изменения нужно коммитить и пушить сразу в `main`, без создания отдельных веток и pull request.

## Стиль кода 1С

- Не добавлять авторские маркеры `//+...` / `//-...`, подписи с фамилией и датой,
  а также закомментированные блоки `БЫЛО` / `СТАЛО`. Историю изменений хранить в Git.
- Не добавлять авторский префикс `бит_` новым методам, реквизитам и командам.
  Использовать стиль соответствующего модуля. Существующее пространство имён
  объектов расширения `бит_омни_` сохранять.
- Эти правила проекта уточняют общие правила авторской маркировки workspace.

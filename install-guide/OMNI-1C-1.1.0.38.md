# Стиль кода Омни — 1.1.0.38

Убраны авторские маркеры и закомментированные блоки прежнего кода из доработок
1.1.0.35–1.1.0.37. Добавленные в этих версиях методы, команды и реквизиты формы
переименованы без авторского префикса. Правило закреплено в `AGENTS.md` проекта.

Поведение чата и рассылок из 1.1.0.37 сохранено. Формула даты из ранее загруженных
стандартных шаблонов поддерживается при чтении без перезаписи данных: заново
загружать шаблоны из-за переименования не требуется.

После резервного копирования установите полное расширение 1.1.0.38 взамен прежней
версии и перезапустите сеансы пользователей и HTTP-публикацию по принятому порядку.
Backend/frontend обновлять не требуется. Проверки новых функций чата описаны в
[инструкции 1.1.0.37](OMNI-1C-1.1.0.37.md).

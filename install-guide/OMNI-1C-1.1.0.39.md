# Исправление синтаксиса конструктора - 1.1.0.39

В модуле `бит_омни_ОбщегоНазначения` устранено обращение к методу непосредственно
после `Новый ХранилищеЗначения(...)`: созданное хранилище сначала присваивается
переменной, затем вызывается `Получить()`.

Предыдущая проверка `/CheckConfig` без явно выбранных контекстов не проверяла
синтаксис всех модулей. При сборке этой версии явно включены `-ThinClient`,
`-Server` и `-ExternalConnection`. В тесты добавлен контроль подобных обращений
после конструктора, поскольку OneScript допускает эту конструкцию.

Также исправлен вызов `ТекущаяДатаСеанса()` в клиентском обработчике кнопки
«Расписание клиента»: используется `НачалоДня(ТекущаяДата())`.

После резервного копирования установите полное расширение 1.1.0.39 взамен прежней
версии и перезапустите сеансы пользователей и HTTP-публикацию по принятому порядку.
Загружать шаблоны повторно и обновлять backend/frontend не требуется.

# Регистрация команды пациента в MAX — 1.1.0.41

В карточку бота добавлена кнопка **Зарегистрировать команды MAX**.
Она получает существующее меню и добавляет `/patient — Выбрать пациента`,
сохраняя остальные команды. Если команда уже зарегистрирована с нужным описанием,
повторного изменения меню нет. Если в меню уже 32 другие команды, операция
останавливается без перезаписи: сначала нужно освободить место.

После установки полного расширения 1.1.0.41 взамен прежней версии откройте
**Омни → Боты → нужный бот**, проверьте канал MAX и токен и нажмите
**Зарегистрировать команды MAX**. Дождитесь сообщения об успешной регистрации.
При вводе `/` в диалоге с ботом появится команда выбора пациента.
Проверка прав на изменение бота выполняется на сервере.

Регистрация использует [официальный метод MAX `PATCH /me/commands`](https://dev.max.ru/docs-api/methods/PATCH/me/commands).
Запрос выполняется только по кнопке; открытие или сохранение карточки бота
не меняет удалённое меню. Backend/frontend обновлять не требуется.
Все изменения версии 1.1.0.40 входят в этот выпуск.

Перед установкой выполните резервное копирование; после обновления расширения
перезапустите сеансы пользователей и HTTP-публикации по принятому порядку.
Во время подготовки выпуска меню реального бота и база клиента не изменялись.

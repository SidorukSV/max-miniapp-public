# Исправление выбора пациента и строки поиска — 1.1.0.42

HTTP-маршрут MAX передавал данные бота структурой, тогда как проверки
принадлежности контакта сравнивали их со ссылкой на справочник ботов.
Из-за несовпадения типов `/patient` не использовал сохранённый телефон,
а повторная передача номера могла завершиться общим отказом в авторизации.
Теперь входящий обработчик приводит данные бота к ссылке до передачи события
обработчикам сообщений и callback. Проверки принадлежности контакта сохранены.

В поиске клиента исправлено имя свойства режима открытия окна.
Для открываемого из Единого чата стандартного поля поиска включено обновление
видимого текста при изменении значения. Переданный номер подставляется без
российского префикса. Для выполнения стандартного поиска нажмите Enter;
номер можно заменить ФИО или другим запросом вручную.

## Установка и проверка

1. После резервного копирования замените полное расширение прежней версии
   на 1.1.0.42; перезапустите пользовательские и HTTP-сеансы по принятому порядку.
   Backend/frontend обновлять не требуется.
2. Проверьте флаг «Заблокирован» в контакте MAX. Интеграция устанавливает его
   при `bot_stopped`; открытие карточки пациента его не снимает. Если контакт
   уже возобновил общение и блокировку нужно снять, сделайте это явно в карточке.
3. Отправьте `/patient` у привязанного контакта. При сохранённом подтверждённом
   телефоне должны прийти кнопки выбора карточек с ФИО и датами рождения.
   При отсутствии проверенного телефона бот сначала запросит собственный контакт.
4. У непривязанного контакта откройте поиск клиента: номер без +7 должен быть
   виден в строке поиска. Выполните поиск Enter, проверьте ручной ввод другого
   запроса и возврат выбранного клиента в поле привязки.

Компиляция тонкого клиента, сервера и внешнего соединения и 26 изолированных
тестов прошли. Добавлен тест формата бота из реального HTTP-маршрута.
Интерактивная проверка в тонком клиенте остановлена пользователем через Esc
до получения результата; видимое заполнение поля и обмен с рабочим MAX требуют
проверки после установки. База клиента при подготовке выпуска не изменялась.

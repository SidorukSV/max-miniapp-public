# Поиск клиента сразу при открытии — 1.1.0.43

Версия 1.1.0.42 заполняла видимую строку поиска номером, но не запускала
штатный обработчик поиска. Результаты появлялись только после редактирования
текста оператором.

Теперь кнопка поиска в Едином чате передаёт номер в метод заимствованной
стандартной формы `ФормаПоискаКлиентаУпр`. Метод заполняет строку и сразу
вызывает существующий `ОбработкаПоискаПоФИО`, который также обрабатывает
телефоны. Поисковый запрос и заполнение таблицы остаются штатными.
Повторное открытие с тем же номером также выполняет поиск; без номера
форма открывается с пустой строкой для ручного ввода.

Обычное открытие формы из календаря не вызывает новый метод.
Выбор возвращается в поле пациента Единого чата; привязка сохраняется
отдельной кнопкой «Привязать пациента».

После резервного копирования замените полное расширение прежней версии
на 1.1.0.43 и перезапустите сеансы по принятому порядку. Frontend/backend
обновлять не требуется. Все предыдущие исправления входят в этот выпуск.

После установки выберите непривязанный контакт с переданным телефоном
и нажмите кнопку поиска: строка должна быть заполнена без +7, а таблица
сразу содержать совпадения без удаления и повторного ввода цифры.
Также проверьте повторное открытие, ручной поиск другого клиента и возврат выбора.

Компиляция тонкого клиента, сервера и внешнего соединения и 27 изолированных
тестов прошли. В тест добавлена проверка запуска штатного обработчика без
события редактирования текста. Интерактивная проверка в базе клиента не выполнялась;
управление окнами после предыдущей остановки через Esc повторно не запускалось.
